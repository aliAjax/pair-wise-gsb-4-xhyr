# License Lens · 合规裁决台

纯前端、可追溯的依赖许可证合规裁决工具。打开 `index.html` 即可使用，所有数据保存在浏览器 localStorage，刷新后裁决时间线完整保留。

## 核心能力

- **依赖清单检查**：每份清单记录创建时间、项目分发方式（SaaS 内部 / 商业分发 / 开源发布 / 嵌入式），逐项保存许可证、结论与判定依据。
- **只增不改的裁决批次**：每次检查生成一个不可修改的裁决批次（含检查时间、规则版本、分发方式快照）。同一依赖在新规则下重检只会追加新批次，旧结论、许可证依据与人工覆盖原因全部保留，可沿时间线逐批核对。
- **分发方式护栏**：GPL / Proprietary 结论与分发方式绑定评估；选择「SaaS 内部分发」不会把高风险标记降成通过（GPL 系最低保留「需复核」，AGPL 网络触发条款下任何分发方式均为高风险），人工覆盖「高风险 → 通过」会被拦截并说明原因。
- **人工覆盖留痕**：覆盖必须填写原因与操作人，记录永久写入对应批次，逐项结论旁标注「已覆盖（原判 X）」。
- **审计导出**：一键导出含全部批次、逐项依据与覆盖记录的 Markdown 审计报告。

## 使用

1. 左侧新建清单：粘贴 `名称@版本 许可证` 每行一条，或上传 package.json / 清单文件，选择分发方式后保存并检查。
2. 右侧切换分发方式或规则版本，点击「重新检查」生成新批次；下方时间线可展开任意旧批次核对。
3. 点击条目「查看依据」可见当前依据与该依赖的完整裁决历史；「覆盖」可录入人工裁决（受护栏约束）。

`src/` 下的 React 脚手架与本工具无关，静态页面不依赖构建步骤。
